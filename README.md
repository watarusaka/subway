# subway

サブスクの支払いと利用状況を、カレンダーで見やすく管理する日本語Webアプリです。

## 起動

```bash
npm install
npm run dev
```

ブラウザーで **http://127.0.0.1:5173** を開きます。

```bash
npm run build      # dist/ に配布用ファイルを生成
npm run preview    # ビルド済みアプリの確認
npm test           # 支払日計算のテスト
npx playwright test  # 起動中の開発サーバーとGoogle ChromeでE2Eテスト
```

## 機能

- 月間カレンダー・リスト表示、月の移動、日別予定、カテゴリ絞り込み
- サブスク登録・編集・削除（月払い・年払い対応）
- 一時停止・利用再開・利用終了の状態管理
- 利用再開時の支払い基準日変更。年払いのカードに月あたりの換算額を併記（端数は円単位に四捨五入し「約」を表示）
- 利用中の月額換算・年額換算、次回支払い、当月の支払い合計
- サービス名検索、利用状況・カテゴリによる絞り込み
- 対象月を選べるサービス別の円グラフ、月の支払予定と予算の比較（年払いは支払月に全額計上）
- 月別・年別の切り替え、1〜12月の積み上げ棒グラフ、サービス別の年間支払予定一覧。棒を選ぶとその月の円グラフに移動
- サービス管理ページへのリンク
- 解約日を指定した解約通知。当日・1・3・7・14・30日前から選択し、「サブスク名」「解約日」の2行を表示。画面右上の「解約通知」に未確認件数・届いた通知・今後の予定を表示
- ブラウザーへの自動保存、JSONバックアップ・復元
- スマートフォン対応、キーボード操作、モーダルのフォーカス制御

初回はサンプルデータで表示します。「自分のサブスクで始める」から登録データをクリアして利用できます。サンプルの価格は参考値です。

## 状態と支払いの扱い

「一時停止」「利用終了」は **subway内の管理状態** です。外部サービスの契約や請求は変更しません。各サービスでの実際の停止・解約・再開手続きは、詳細画面の「サービスの管理ページ」から行ってください。

利用中のサービスだけが支払予定と支出集計に含まれます。基準日以降、月払いは毎月同じ日、年払いは毎年同じ月日に予定を表示します。31日や2月29日が存在しない月・年はその月の末日に調整します。再開画面で支払い基準日を変更できます。変更しなければ登録済みの基準日を利用し、変更した場合は指定日以降の予定を計算します。

集計は現在の登録内容による見込みであり、過去の請求履歴や実際の決済を記録するものではありません。金額は日本円・整数で管理します。

## 保存方式

### 解約通知

追加・編集画面の「解約通知を設定する」をオンにし、解約日と何日前に通知するかを設定します。解約日の初期値は支払い基準日の1か月後（月末調整あり）、通知日数は3日前です。当日・1・2・3・7・14・30日前から選べます。手動で解約日を変更するまでは支払い基準日の変更に追従します。一時停止中も通知対象で、利用終了・削除・通知オフにしたものは対象外です。

通知時刻は日本時間の午前9時です。起動中は次の通知時刻へのタイマーを設定し、起動時・表示復帰時・1分間隔でも確認します。通知内容は `サブスク名：サービス名` と `解約日：YYYY/MM/DD` の2行です。右上の「解約通知」から確認済みにできます。ブラウザー通知を許可した環境ではデスクトップ通知も試行します（OSやブラウザーの通知設定によります）。

アプリを閉じた状態での自動配信・メール通知には対応していません。閉じている間や端末のスリープ中の9時配信は保証できません。通知時刻を過ぎてから開いた場合は、その時点で通知します。解約日を過ぎても未確認通知は残ります。自動解約は行いません。旧バージョンからのデータを保持するため、保存キーは従来のものを利用します。

フロントエンド単体で動作し、データはこのブラウザーの `localStorage` に保存します。アカウント認証・端末間同期・外部サービスとのAPI連携はありません。ブラウザーデータの削除や利用URLの変更によって保存情報が利用できなくなるため、設定画面からJSONバックアップを保存してください。

## 構成

- `src/main.js` — 画面と操作・データ保存
- `src/model.js` — 支払い計算とサンプルデータ
- `src/style.css` — レスポンシブデザイン
- `tests/model.test.js` — 月末・うるう年・利用状態の検証
- `tests/app.spec.js` — 登録から状態変更・復元・モバイル表示までの動作検証

Vite / JavaScript / Lucide を使用しています。Google Fontsにアクセスできない場合はシステムフォントで表示します。
